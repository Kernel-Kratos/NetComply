Scope

Now, next, and limits.

Now

  • Cisco IOS, Juniper, MikroTik
  • 10 checks, CIS mapping
  • Training loop with re-audit
  • Dashboard and per-device PDF

Next

  • AWS / Azure security groups, SONiC
  • NIST, STIG, ISO rule sets
  • Live collection via Netmiko / NAPALM
  • Screenshot ingestion for GUI-only firewalls

Honest limits

  • Fixes are suggestions, so test first
  • Coverage grows as admins train it
  • Read-only: never touches live devices
  • Framework control IDs pending verification
